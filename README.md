## Intern Information
**Name:** Ayesha Ahsan

**Week:** Week 2
## Project
Responsive Personal Portfolio / Landing Page
This project is a responsive personal portfolio webpage
created using HTML5 and CSS3 as part of Week 2 of the
AUREX Full-Stack Engineering Internship.
## CSS Features and Layout Techniques
- CSS3 syntax
- Element selectors
- Class selectors
- ID selectors
- Colors and backgrounds
- Fonts and typography
- Text styling
- Display properties
- Positioning
- CSS Box Model
- Width and height
- Margin and padding
- Borders
- Flexbox
- CSS Grid
- Grid rows and columns
- Gap spacing
- Media Queries
- Responsive Web Design
### Flexbox
Flexbox is used for the navigation and form layout.
The project uses:
- flex-direction
- justify-content
- align-items
- gap
### CSS Grid
CSS Grid is used for the Skills section.
The layout changes according to screen size:
- Mobile: 1 column
- Tablet: 2 columns
- Desktop: 3 column
## Responsive Design
The website is responsive for:
- Mobile
- Tablet
- Desktop
CSS media queries are used to adjust the layout for different screen sizes.
## Key Learnings
During Week 2, I learned how to use CSS3 to style a webpage
and create responsive layouts.
I practiced:
- CSS Box Model
- Flexbox
- CSS Grid
- Media Queries
- Typography
- Spacing
- Colors
- Responsive Web Design
## Challenges
The main challenge was making the webpage responsive
for different screen sizes.
I solved this by using Flexbox, CSS Grid, media queries,
and appropriate spacing.
